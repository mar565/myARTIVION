# MyARTIVION PWA

## Azure Static Web Apps Configuration

### Output Directory
Since this is a static website, all files are already in the root directory.
The build script generates PWA icons but does not create a separate build folder.

### Configuration
- **App location**: `/` (root)
- **Output location**: `/` (root - no separate build output)
- **Skip app build**: No (we run icon generation)
- **Build command**: `npm run build` (generates PWA icons)

### Build Process
The build script (`npm run build`) does:
1. Generates PWA icons from the logo
2. Confirms static files are ready

All HTML, CSS, JS, and assets are served directly from the repository root.
